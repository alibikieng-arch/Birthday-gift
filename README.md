# Birthday Gift — Reference-matched edition

A responsive single-page birthday surprise designed around the supplied reference artwork.

## Deploy to GitHub Pages
1. Put the contents of this folder in the repository root.
2. Ensure `index.html` is at the repository root.
3. GitHub → Settings → Pages → Deploy from a branch → `main` → `/ (root)`.

## Notes
- The room artwork is local, so the page does not depend on an external image host.
- Countdown uses the visitor's local device time and freezes at zero from October 1 00:00 through October 4 00:00.
- Password authentication is only a frontend experience and is not production security.
- Uploaded videos are local browser session object URLs only.
